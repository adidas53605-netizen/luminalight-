# LuminaLight — Premium Architectural & Interior Lighting

A modern, luxurious, and fully responsive e-commerce website for LuminaLight, an architectural lighting atelier inspired by high-end design houses.

## ✨ Features

- **Architectural Design System:** Sophisticated luxury aesthetic with deep charcoal, warm white, light sand, and champagne gold accents.
- **Interactive Light Ambience Switcher:** Preview warm golden (2700K) and natural studio (3500K) lighting atmospheres.
- **8 Dedicated Pages:**
  - **Home:** Full-width hero section, featured categories, 8 signature luminaires, promotional banner, standard pillars, brand story, client testimonials, and newsletter.
  - **Shop / All Products:** Live filtering by category, keyword search, price range filter, sorting (Featured, Price: Low/High, Rating), and grid column toggles.
  - **Product Details:** Multi-image gallery with zoom, 2700K / 3000K / 4000K color warmth selector, tabbed specifications, and customer reviews.
  - **Categories:** Detailed showcase of all 6 lighting typologies with spatial room placement recommendations.
  - **About Us:** Brand genesis, craftsmanship pillars, and metrics counter.
  - **Contact Us:** Interactive inquiry form, flagship atelier addresses (Mumbai, Delhi, Bengaluru), and FAQ accordion.
  - **Wishlist:** Private collection with move-to-bag and removal actions.
  - **Shopping Cart & Checkout:** Free shipping meter, privilege promo codes (`LUMINA10`, `ARCHITECT15`), and a simulated 3-step checkout experience with order confirmation reference.
- **Global Modals & Drawers:** Slide-over cart drawer, instant search modal, quick view preview modal, and floating toast notifications.

## 🛠️ Tech Stack

- **React.js** (v18)
- **Vite** (v5)
- **Tailwind CSS** (v3)
- **Lucide React** (Icons)
- **React Router DOM** (v6)

## 🚀 Getting Started

### Prerequisites

Ensure [Node.js](https://nodejs.org/) (v18+) is installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/adidas53605-netizen/LuminaLight.git

# Navigate into the project folder
cd LuminaLight

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
```

The output will be generated inside the `dist/` directory, ready for immediate deployment on [Vercel](https://vercel.com).
